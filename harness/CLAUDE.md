# 稼働報告アプリ

SES契約の稼働を登録して、月ごとの精算額（超過・控除）を出す社内向けのアプリ。

## 技術

- Next.js 16（App Router）／TypeScript（strict）
- データベースは使わない。`data/*.json` を読み書きする
- テストは vitest。`npm test` で回る

## どこに何があるか

- `src/app` … 画面と API
- `src/lib` … 業務の計算。計算はすべてここに置く
- `src/lib/__tests__` … テスト
- `data` … メンバーと稼働報告の JSON
- `docs` … 先方との定例の議事録

## 言葉

- 精算幅 … 契約で決めた稼働時間の下限と上限。この範囲なら月額そのまま
- 超過 … 上限を超えた分。1時間あたり「月額 ÷ 上限」を足す
- 控除 … 下限に足りない分。1時間あたり「月額 ÷ 下限」を引く

## 進め方

1. 直す前に、原因を調べて報告する。調査と修正を同じ依頼で混ぜない
2. 直す前にテストを書く。落ちることを確認してから直す
3. 1回の作業で触るのは1つのことだけ
4. 終わりに `npm test` を通してから報告する

## やらないこと

- `git commit` / `git push` を実行しない
- 依存パッケージを追加しない
- 既存のテストを消さない・書き換えない
- `data/*.json` を手で書き換えない
