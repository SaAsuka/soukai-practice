次の不具合を直してください。

$ARGUMENTS

この順番を必ず守ってください:

1. いまの間違った挙動を再現するテストを書く
2. `npm test` を実行して、そのテストが落ちることを確認する
3. `.claude/rules/domain.md` と `.claude/rules/coding.md` を読む
4. 直す。触るファイルは必要最小限にする
5. `npm test` を実行して、全部通ることを確認する
6. 変えた場所と、なぜその直し方にしたかを3行で報告する

2 でテストが通ってしまった場合は、再現条件が違います。直す前に報告してください。
