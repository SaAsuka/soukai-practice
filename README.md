# 稼働報告アプリ（練習用）

年末AI総会の演習で使うリポジトリです。

**実在の案件ではありません。** 登場する氏名・会社・単価・稼働時間はすべて演習用に作った架空のもので、実在の人物や取引とは関係ありません。

月ごとの稼働時間を登録して、契約の精算幅（下限・上限）にもとづいて支払額を出す小さなアプリです。

## 動かす

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # テストを回す
```

データベースは使っていません。`data/` の JSON ファイルを読み書きしています。

## 画面

| パス | 内容 |
|---|---|
| `/` | 稼働の一覧 |
| `/new` | 稼働の登録 |
| `/summary` | 月次の精算（`?ym=2026-08` で月を指定） |

## 用語

- **精算幅** … 契約で決めた稼働時間の下限と上限。この範囲なら月額そのまま
- **超過** … 上限を超えた分。1時間あたり「月額 ÷ 上限」が加算される
- **控除** … 下限に足りない分。1時間あたり「月額 ÷ 下限」が差し引かれる

## このリポジトリの使いかた

`docs/` に、先方との定例の議事録が入っています。**そこに書かれている困りごとを、自分で読み取って直すところから始めてください。**
仕様書は用意していません。何を直すべきかを決めるところが演習の一部です。

`npm test` は通ります。テストが通ることと、正しく動くことは別です。

## harness/ について

当日④で配る規約一式（ハーネス）が入っています。**当日まで開かなくて大丈夫です。**
入れ方と外し方は `harness/README.md` にあります。

なお `npm run dev` を実行すると、Next.js がリポジトリ直下に `CLAUDE.md` と `AGENTS.md` を自動生成します
（フレームワーク自身の説明が入ります）。この2つは Git の管理対象から外してあります。
